# 就活管理アプリ (job-hunt-manager)

就活生がエントリー企業の情報、選考ステータス、ES締切、マイページURLを一元管理できる軽量で直感的なWebアプリケーションです。

---

## 📌 アプリ概要
就職活動では、エントリー企業の増加に伴い「ES締切の見落とし」「マイページURLの紛失」「各社の選考進捗の把握難」といった課題が頻発します。  
本アプリは、ブラウザだけで手軽に起動でき、シンプルかつ見やすいUIで企業ごとの状況をひと目で把握・整理できる管理ツールです。

---

## 🎯 作成目的
- **ES提出期限の厳格な管理**: 直近3日以内の締切を視覚的に強調し、出し忘れを防止する。
- **情報の一元集約**: 企業名、業界、志望度、選考段階、マイページ、メモを1箇所に集約し、就活作業の効率化を図る。
- **手軽な導入と利用**: 面倒なアカウント作成やバックエンド環境構築を不要にし、ブラウザ単体（localStorage）で即座に使える環境を提供する。

---

## 🚀 主な機能

1. **企業情報の登録・編集・削除 (CRUD)**
   - 企業名、業界、ES締切、選考状況、志望度（★1〜3）、マイページURL、メモの登録
   - 登録済み企業情報の編集（同一フォームを新規・編集で共用）
   - 不要になった企業データのワンクリック削除（確認ダイアログ付き）

2. **リアルタイム検索・絞り込み**
   - **企業名フリーワード検索**: 入力と同時にリアルタイムで部分一致検索
   - **業界絞り込み**: IT・通信、メーカー、金融、商社、サービス、その他
   - **選考状況絞り込み**: 未エントリー、エントリー済み、ES作成中、ES提出済み、Webテスト、面接、内定
   - 複数条件を組み合わせた複合フィルタリングに対応

3. **ES締切管理・ソート機能**
   - **締切間近アラート**: 当日および3日以内の締切を赤系のアラートバッジと強調ボーダーで目立たせて表示
   - **締切終了判定**: 提出期限が過ぎた企業は「締切終了」としてトーンダウン表示
   - **多彩な並び替え**:
     - ES締切が近い順（直近有効な締切を最優先、次に未来、締切終了、未設定の順でソート）
     - 登録が新しい順 / 古い順
     - 志望度が高い順

4. **洗練されたレスポンシブUI**
   - 就活支援サービスらしい清潔感と信頼感のあるカード型デザイン
   - PCでは複数列のカードグリッド、スマートフォンでは操作しやすい1列レイアウトに自動最適化
   - タップしやすいボタンサイズと視認性の高いステータス表示

---

## 🛠️ 使用技術
- **HTML5**: セマンティックなマークアップ
- **CSS3**: Flexbox、CSS Grid、CSS変数、メディアクエリ（レスポンシブ対応）
- **JavaScript (Vanilla JS / ES6+)**: フレームワークや外部ライブラリに依存しないピュアJavaScript設計
- **ブラウザストレージ**: `localStorage` によるデータの永続化

---

## 💻 起動方法
外部サーバーの立ち上げやパッケージインストールは不要です。

1. 本リポジトリをクローンまたはダウンロードします。
   ```bash
   git clone https://github.com/kado256/job-hunt-manager.git
   ```
2. フォルダ内の `index.html` をお好みのブラウザ（Google Chrome、Microsoft Edge、Safari など）でダブルクリックして開きます。
3. すぐに企業の登録や管理を開始できます。

> **Tips**: 簡易ローカルサーバーを使用したい場合は、以下のように起動することも可能です。
> ```bash
> # Pythonを使用する場合
> python -m http.server 8000
> # ブラウザで http://localhost:8000 にアクセス
> ```
