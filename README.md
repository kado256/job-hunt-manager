# 就活管理アプリ (job-hunt-manager)

就活生がエントリー企業の情報、選考状況、ES締切、マイページURLなどを一元管理できるWebアプリケーションです。

---

## 📌 アプリ概要

就職活動では、エントリーする企業が増えるにつれて、ESの締切や選考状況、企業ごとのマイページなど、管理する情報も増えていきます。

その結果、

- ES締切を見落とす
- 企業ごとの選考状況が分からなくなる
- マイページURLを探すのに時間がかかる
- 複数企業の情報が分散してしまう

といった問題が起こりやすくなります。

本アプリは、こうした就職活動に関する情報を一元管理し、企業ごとの状況を分かりやすく整理することを目的として開発しました。

---

## 🎯 作成目的

- **ES提出期限の管理**
  - 直近3日以内の締切を視覚的に強調し、提出忘れを防止する

- **企業情報の一元管理**
  - 企業名、業界、志望度、選考状況、マイページURL、メモなどを1か所にまとめて管理する

- **就職活動の効率化**
  - 検索・絞り込み・並び替え機能によって、必要な企業情報をすぐに確認できるようにする

- **シンプルな構成**
  - アカウント作成やバックエンドを必要とせず、ブラウザの `localStorage` を利用してデータを管理する

---

## 🚀 主な機能

### 1. 企業情報の登録・編集・削除

企業ごとに以下の情報を管理できます。

- 企業名
- 業界
- ES締切
- 選考状況
- 志望度（★1〜3）
- マイページURL
- メモ

登録済みの企業情報は後から編集できます。

また、不要になった企業情報は確認ダイアログを表示した上で削除できます。

---

### 2. リアルタイム検索・絞り込み

企業一覧から目的の企業を探しやすくするため、以下の機能を実装しています。

- **企業名検索**
  - 入力した文字列による部分一致検索

- **業界による絞り込み**
  - IT・通信
  - メーカー
  - 金融
  - 商社
  - サービス
  - その他

- **選考状況による絞り込み**
  - 未エントリー
  - エントリー済み
  - ES作成中
  - ES提出済み
  - Webテスト
  - 面接
  - 内定

複数の条件を組み合わせた絞り込みにも対応しています。

---

### 3. ES締切管理・並び替え

ESの提出期限を確認しやすくするため、締切日に応じて表示を変更します。

- **締切間近の強調表示**
  - 本日締切の場合は「本日締切！」と表示
  - 3日以内の場合は「あと○日！」と表示
  - 赤系のテキスト・背景・カード左端のラインで強調

- **締切終了判定**
  - 提出期限を過ぎた企業は「締切終了」と表示
  - カード全体をトーンダウンして表示

- **並び替え**
  - ES締切が近い順
  - 登録が新しい順
  - 登録が古い順
  - 志望度が高い順

---

### 4. レスポンシブ対応

PCとスマートフォンの両方で利用できるようにレスポンシブデザインを実装しています。

- PCでは複数列のカードレイアウト
- スマートフォンでは1列表示
- スマートフォンでも操作しやすいボタンサイズ
- 企業情報を確認しやすいカード型UI

## 💾 データ保存について

登録した企業情報は、ブラウザの `localStorage` に保存されます。

そのため、以下の点に注意してください。

- データは現在使用しているブラウザ内に保存されます
- サーバーへのデータ送信は行いません
- 別のブラウザとはデータを共有しません
- 別の端末とはデータを共有しません
- ブラウザのサイトデータを削除すると、登録した企業情報も削除されます

現在は個人利用を想定した構成です。

今後は、JSONやCSV形式によるデータのエクスポート・インポート機能を追加し、バックアップや別端末へのデータ移行ができるようにすることを検討しています。

## 💻 起動方法

本アプリはHTML / CSS / JavaScriptのみで構成されており、バックエンドや追加パッケージのインストールは必要ありません。

### 1. リポジトリをクローン

```bash
git clone https://github.com/kado256/job-hunt-manager.git
```

### 2. プロジェクトフォルダへ移動

```bash
cd job-hunt-manager
```

### 3. 簡易HTTPサーバーを起動

WindowsでPython Launcherを使用する場合：

```bash
py -m http.server 5500
```

その他の環境では：

```bash
python -m http.server 5500
```

### 4. ブラウザでアクセス

以下のURLをブラウザで開きます。

```text
http://localhost:5500/
```

企業情報の登録・編集・削除などの機能を利用できます。
