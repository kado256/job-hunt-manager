# 就活管理Webアプリ 機能追加およびUI改善 実装計画書

## 1. 概要
本ドキュメントは、HTML / CSS / Vanilla JavaScript で構築された就活管理Webアプリ（`job-hunt-manager`）の機能追加およびUI改善の設計・実装方針をまとめた開発記録です。

---

## 2. 実装方針と技術制約
- **フレームワーク不使用**: Vanilla JavaScript、HTML5、CSS3 のみで構成。
- **データ永続化**: ブラウザの `localStorage` を使用。
- **完全な後方互換性**: 既存データ形式（`id`, `name`, `industry`, `deadline`, `status`, `priority`, `myPageUrl`, `memo`）を完全に維持。
- **段階的実装**: Stepごとにブランチを作成（`feature/*`）し、動作検証を経て `main` へ反映。

---

## 3. 実装内容

### Step 1: 企業情報の編集機能
- **ブランチ**: `feature/edit-company`
- **変更内容**:
  - `company-form.html` を新規登録と編集で共用化。
  - URLパラメータ `?id=<companyId>` を解析し、該当企業の既存情報をフォームに自動バインド。
  - 編集モード時はタイトルやボタン文言を「企業情報を編集」「更新」に動的切り替え。
  - 送信時に既存IDを保持したまま `localStorage` のデータを更新。
  - 一覧画面の各企業カードに「編集」ボタンを追加。

### Step 2: 検索・絞り込み機能
- **ブランチ**: `feature/search-filter`
- **変更内容**:
  - `index.html` に検索・フィルターUI（企業名フリーワード検索、業界セレクト、選考状況セレクト）を追加。
  - `js/main.js` に `renderCompanies()` 関数を実装し、リアルタイムでフィルタリング描画。
  - 条件一致0件時および全データ0件時それぞれに応じた案内メッセージを表示。

### Step 3: ES締切管理機能
- **ブランチ**: `feature/deadline-management`
- **変更内容**:
  - ES締切日（`deadline`）と当日日付を比較し、残り日数を算出するロジックを実装。
  - **締切間近（3日以内）**: `(本日締切！)` や `(あとX日！)` の強調テキストおよびバッジを付与。
  - **締切終了（過去日）**: `(締切終了)` 表示および落ち着いたトーンへのスタイル切り替え。
  - **並び替え（ソート）**: 「ES締切が近い順（直近有効→未来→締切終了→未設定）」を最優先オプションとして提供。さらに「登録が新しい順」「古い順」「志望度が高い順」もサポート。

### Step 4: UI改善 & レスポンシブ対応
- **ブランチ**: `feature/ui-improvement`
- **変更内容**:
  - 就活支援サービスらしい清潔感・信頼感のあるカラーパレット（インディゴ/ブルー基調）を採用。
  - 企業一覧をカード型グリッドレイアウトで表示し、視認性を向上。
  - 締切3日以内のカードには左端レッドバーと警告背景を適用し、期限切れカードはスレートトーンに調整。
  - PCおよびスマートフォン（画面幅640px以下）に対応したレスポンシブデザイン（CSS Flexbox / Grid、メディアクエリ）。
  - 各種ボタン（追加、編集、削除、マイページ）のデザインと押しやすさを改善。

### Step 5: ドキュメント整備
- **ブランチ**: `feature/docs-update`
- **変更内容**:
  - `README.md` をポートフォリオや利用者にわかりやすい構成で全面刷新。
  - `docs/implementation_plan.md` に開発記録として本設計書を保存。

---

## 4. 検証結果
- 新規登録、編集、更新、削除のCRUD処理が正常に完了。
- フリーワード検索、業界・選考状況の単独および複合絞り込みが正常に機能。
- 締切判定（本日締切、3日以内、締切終了、余裕あり、未設定）およびソートが正確に動作。
- PC表示およびモバイル画面でのレイアウト崩れがないことを確認。
